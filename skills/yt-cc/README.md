# yt-cc, explained for people

Someone sends you a video and asks what it says. Watching it costs the length of the
video. Sending the frames to an AI model costs real money per minute. But the creator
already wrote or generated captions, and YouTube already serves them as text. This tool
pulls that text, plus the description and metadata, to a local markdown file in one
command.

## What you get

A folder per video with:

- `transcript.md`: the title, channel, duration and date, the creator's own description
  (which often holds the links and corrections), the chapters if there are any, and the
  transcript with a timestamp about once a minute.
- `transcript.json` and `meta.json` for anything programmatic.
- The poster frame, and the video file itself only if you ask for it.

## Why it tells you where the captions came from

The transcript says whether the captions were written by a person or generated by a
machine. Human captions are worth quoting word for word. Machine captions are fine for
meaning but mishear names and drop punctuation. When you quote from one, say which it
was.

## Why it reads the description first

The description is often the fast answer: the list of tools used, the link to the
repo, the pinned correction. A video with no captions at all still gets its description
saved, so you are rarely left with nothing.

## A whole channel

Give it a channel or playlist URL and it lists every video in one request, skips the
ones already saved, and fetches the rest with a pause between each. Use the limit flag
the first time on an unfamiliar channel so you find out it has three thousand videos
before you download three thousand transcripts.

## What it cannot do

Anything shown on screen but not spoken is gone. Code on a slide, a diagram, a demo of a
user interface, a prompt the presenter reads silently. If that is the question, no
transcript will answer it and retrying will not help.

## The board

It can serve every saved transcript as a searchable page on your own machine, bound to
localhost only.

## Requirements

Python 3 and `yt-dlp`. If `yt-dlp` is missing the tool says how to install it.
